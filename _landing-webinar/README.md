# Лендинг «Как инвестировать в 2026 году» — Tilda-пакет

Пять самостоятельных секций для копи-пасты в блоки T123 (HTML-код) Тильды. Каждый файл — отдельный экран, со своими стилями, не конфликтует с резетами Тильды.

## Файлы

| Файл | Что это |
|---|---|
| `01-hero.html` | Первый экран: эйбрау, дата, заголовок «Как инвестировать в 2026 году» с синей пилюлей на «2026», подзаголовок, синяя кнопка регистрации |
| `02-benefits.html` | «На вебинаре Вы:» — 5 нумерованных карточек с буллетами |
| `03-author.html` | Тёмная секция: фото Татьяны + 6 регалий + блок с логотипами медиа |
| `04-testimonials.html` | 6 карточек-плейсхолдеров под отзывы + ссылка на @invest_prosto_otziv |
| `05-cta.html` | Синяя финальная секция с большой белой кнопкой регистрации |
| `tatyana.jpg` | Фото для блока «Вебинар ведёт» |
| `preview.html` | Все пять секций склеены в одну страницу — открой локально, чтобы увидеть как ленд выглядит целиком |

## Как вставить в Тильду

1. Открой страницу ленда в Тильде → редактирование.
2. На каждое место вставь блок **T123 — Код HTML**.
3. Открой соответствующий файл из этого пакета, скопируй ВЕСЬ содержимое (включая `<link>` со шрифтами, `<style>` и разметку).
4. В блоке T123 вставь как код, опубликуй.

Порядок секций — 01 → 02 → 03 → 04 → 05.

## Что нужно заменить перед публикацией

### 1. URL кнопки регистрации
Поиск по всем файлам: `href="#registration"` (4 места — в hero, в final CTA, и в превью). Замени на реальный URL формы (Тильда-форма, GetCourse-ссылка, Senler — что у тебя в боевом потоке).

### 2. Фото Татьяны (03-author.html)
Загрузи `tatyana.jpg` в медиатеку Тильды (Settings → File library), получи URL вида `https://static.tildacdn.com/...`. Найди в `03-author.html` строку:
```html
<img src="https://placehold.co/640x800/..." alt="Татьяна Бунегина">
```
Замени `src` на свой URL.

### 3. Логотипы медиа (03-author.html)
В блоке `.lp-author__media-row` сейчас 4 текстовых плейсхолдера «Медиа 1…4». Варианты:
— Загрузи реальные PNG-логотипы в Тильду, замени `<div class="lp-author__media-logo">…</div>` на `<img class="lp-author__media-logo" src="...">` с правкой стилей под картинки
— Оставь текстом, замени «Медиа 1» на реальные названия (Forbes, РБК и т.п.)
— Если логотипов нет — удали весь блок `.lp-author__media` целиком (от `<div class="lp-author__media">` до закрывающего `</div>`)

### 4. Отзывы (04-testimonials.html)
Сейчас 6 карточек с одинаковым плейсхолдер-текстом. Замени:
— `<span class="lp-testimonial__name">Имя ученика</span>` → реальное имя
— `<span class="lp-testimonial__role">портфель / срок обучения</span>` → роль (например «портфель 3 млн, в Академии год»)
— `<p class="lp-testimonial__text">«Цитата отзыва…»</p>` → реальная цитата
— Буква в `.lp-testimonial__avatar` — первая буква имени (А/М/Е/С/И/Н — поменять на нужные)

Альтернативно — пришли мне скриншоты отзывов из @invest_prosto_otziv, я заменю на картинки.

## Цветовая система

Если потом захочется одинаково отредактировать цвета — в каждом файле повторяются:
- `#F1ECE0` — кремовый фон страницы
- `#0B0B0B` — основной чёрный текст
- `#3429D2` — фирменный синий
- `#F0C24A` — жёлтый акцент (пилюли)
- `#C7E5C4` — мятный (аватар)
- `#F8B5A6` — коралл (аватар)
- `#4A4036` / `#6B5F52` — приглушённый коричневый-серый для подписей

Шрифт: **Onest** (загружается с Google Fonts в каждой секции).
