## Резюме

Фундаменталка v1.0 — рабочее приложение с современным bento-дизайном в фирменных цветах академии. Биржевые данные, мультипликаторы, дивиденды, графики цен, сравнение и календарь работают. Данные обновляются автоматически еженедельно, описания компаний сгенерированы DeepSeek.

Аудит выявил три группы замечаний: правовые (необходимы перед публичным запуском в РФ), безопасностные (риски при росте трафика и при подключении любых форм), UX/качество кода (полировка под массовую аудиторию).

В версии v2.0 закрыты блокеры и приоритетные замечания. Список ниже — для информации и дальнейших итераций.

## 2. ВЫСОКИЙ ПРИОРИТЕТ (закрыть до массового релиза)

| № | Что | Где | Решение в v2 |
|---|---|---|---|
| 2.1 | Нет Content Security Policy | `<head>` index.html | **Закрыто:** добавлен CSP-meta с whitelist для cdn.jsdelivr.net, fonts.googleapis.com, iss.moex.com, supabase.co |
| 2.2 | `target="_blank"` без `rel="noopener noreferrer"` | 4 места в HTML | **Закрыто** |
| 2.3 | viewport блокирует зум — accessibility-минус, особенно для пожилой аудитории | строка 5 | **Закрыто:** убран `maximum-scale=1.0, user-scalable=no` |
| 2.4 | `showHint` пишет в `innerHTML` без экранирования (мёртвый код, но XSS-вектор) | строка 521 | **Закрыто:** заменено на `textContent` |
| 2.5 | Race condition: быстрое переключение компаний → данные одной перерисовываются поверх другой | `loadCompany`, `drawPriceChart` | **Закрыто:** добавлен счётчик `loadSeq` — устаревшие ответы игнорируются |
| 2.6 | Stub-блоки выглядят как «недоделанные баги» на каждой вкладке | разные | **Закрыто:** убраны, оставлены только осмысленные подсказки источников |
| 2.7 | DeepSeek-описания публикуются без проверки человеком — потенциальный риск по деловой репутации | таблица `emitters.description` | **Закрыто частично:** добавлена пометка «описание сгенерировано ИИ, проверяйте по официальным источникам». Промпт DeepSeek уже строго факт-ориентированный (запрещены оценочные слова) |
| 2.8 | Табы недоступны с клавиатуры (нет ARIA `role="tablist"`) | `.tabs`, `.tab` | **Закрыто:** добавлены role/aria-selected, фокус-стили |

## 3. СРЕДНИЙ ПРИОРИТЕТ (полировка)

### UX / дизайн

- **Hover на тач-устройствах прилипает.** v2: `@media (hover: hover)` для всех `:hover`-стилей.
- **Цвет `tile-cream` сливается с фоном страницы.** v2: `tile-cream` отдалён от фона за счёт более контрастной рамки и тени.
- **Светофор зон (зелёный/жёлтый/красный) полагается только на цвет — для дальтоников плохо.** Можно добавить иконки или микро-индикаторы. Пока оставлено.
- **Цвета на иконках и иерархии bento-плиток.** UX-эксперт предложил иконки в углах, sparkline в hero. Оставлено для v3.
- **Mobile-first: `bento-third` ломается на «2 + сирота» при двух колонках.** v2: на мобильных третая плитка делается full-width.
- **Тач-таргеты `<button class="btn-add">` меньше 44×44.** v2: размеры подняты до HIG-минимума.
- **Tabs скроллятся горизонтально без визуального индикатора.** Оставлено: на узких экранах иконка-тень справа; полное переосмысление навигации — v3.

### Безопасность / архитектура

- **`raw JSONB` в Supabase должен отдаваться через VIEW без raw-полей.** Оставлено для v3.
- **Rate-limit в Supabase API.** Включить через панель Supabase.
- **Lazy-load Chart.js (200 КБ).** Оставлено для v3 — экономит трафик при первом открытии.
- **Глобальные переменные → `App.state` namespace.** Оставлено для v3.
- **Юнит-тесты `zoneFor`, `groupByEmitter`, `matchesEmitter`.** Оставлено для v3.
- **Парсинг smart-lab/dohod.** Юрист рекомендовал переход на e-disclosure для дивидендов и расчёт мультипликаторов из MOEX+отчётности — это снимает риск спора о правах на базу данных. Это большая работа, оставлена в roadmap.

### Регуляторика и контент

- **Возрастная маркировка.** В v2 поставил «16+» в footer как нейтральную информационную категорию; «18+» убран из текста (избыточно).
- **Отдельная Политика обработки ПДн.** Сейчас интегрирована в legal.html. По 152-ФЗ ст. 18.1 ч. 2 п. 2 — это допустимо, но лучше вынести отдельной страницей с отметкой согласия пользователя при первом входе. Оставлено для v3 — после уточнения, какие данные на самом деле собираются.
- **AI-описания — модерация.** Добавить в Supabase колонку `description_reviewed BOOLEAN`, показывать только проверенные. v3.

## 4. Что делать дальше (рекомендации в roadmap)

### Этап «v2 ⇒ публичный релиз»
- Татьяна: заполняет реквизиты в legal.html, подаёт уведомление в РКН (15 минут).
- Татьяна: получает домен, переключается с trycloudflare.com на постоянный (рекомендую `fundamentalka.invest-prosto.ru` или подобное).
- Тим: переходит в скрипте парсинга на e-disclosure для дивидендов, чтобы убрать зависимость от smart-lab/dohod.

### Этап «v3 — для роста»
- Lazy-load Chart.js, preconnect, очистить console.log в проде.
- Состояние в `App.state`, разделить на модули.
- Юнит-тесты на `zoneFor` и парсинг dividends.
- VIEW в Supabase без `raw` JSONB, rate-limit.
- Полная ARIA-разметка, фокус-индикаторы, тестирование со скринридером.
- Иконки в плитках, sparkline в hero.

### Этап «v4 — расширение»
- Авторизация ученика академии через Telegram WebApp + GetCourse Webhooks (по мастер-документу).
- Раздел инсайдеров с надёжного источника, как только Татьяна назовёт его.
- Календарь отчётностей + рекомендаций СД (после получения доступа к e-disclosure).

## 5. Откат к v1.0

```bash
cd /root/TIM/projects/fundamentalka
git checkout v1.0   # тег зафиксирован 10 мая 2026
```

После отката — пересобрать single-file в `.www`:
```bash
SLUG=$(cat /tmp/.www-slug)
python3 -c "
import re
css = open('investprosto-design.css').read()
html = open('index.html').read()
inlined = re.sub(r'<link rel=\"stylesheet\" href=\"investprosto-design\\.css\">',
  '<style>\\n' + css + '\\n</style>', html, count=1)
open('/root/TIM/.www/$SLUG/index.html', 'w').write(inlined)
"
```

Тэги в репозитории:
- `v1.0` — версия до аудита (10 мая 2026, коммит `e3e3be2`)
- `v2.0` — версия после фиксов (создаётся после применения правок)
